# 3. Python

Módulo de Python, focado só no que serve pra engenharia de dados. Começa pelo porquê de Python ser a linguagem da área e pelos fundamentos, e depois aplica a linguagem a dado. É um resumo do resumo, não um curso completo de Python.

1. [Python: a caixa de ferramentas do engenheiro de dados](01-por-que-python.md) — o que é Python, por que ele e não outra linguagem, por que caixa de ferramentas e não canivete suíço, onde ele aparece no ciclo de vida, e o que esse módulo vai (e não vai) cobrir.
2. [Preparando o terreno: o que você precisa instalar antes de escrever Python](02-preparando-o-terreno.md) — o que é interpretador e IDE, por que o curso usa VS Code, e o passo a passo pra instalar Python e VS Code no Windows.
3. [Variável e tipo de dado: como o programa guarda informação](03-variavel-e-tipo-de-dado.md) — o que é uma variável, como receber valor digitado com `input()`, os tipos básicos (string, int, float, bool), os operadores matemáticos, tipagem dinâmica, e um primeiro exemplo prático.
4. [Texto (string): o dado que mais dá trabalho pra limpar](04-texto-string.md) — por que texto livre é a sujeira mais comum em dado, indexação e fatiamento, métodos de limpeza (strip, upper/lower, replace, split, join), o `in`, f-string, e um exemplo de limpeza.
5. [Comparação e condicional: ensinando o programa a decidir](05-comparacao-e-condicional.md) — operadores de comparação e booleano, if/else, indentação, elif, operadores lógicos (and, or, not), condicional aninhado, e um exemplo que junta tudo.
6. [Repetição (loop): deixando o trabalho chato pro programa](06-repeticao-e-loop.md) — for com range(), for direto numa string ou lista, while, a diferença entre os dois, break e continue, e um exemplo processando leituras de sensor.
7. [Até dragões precisam de dados](07-estrutura-de-dado.md) — estrutura de dado contada numa história de RPG: dicionário, lista, tupla, set, enumerate(), list comprehension, e quando usar cada uma.
8. [Função: do pão com manteiga ao bolo](08-funcao.md) — o que é função e por que existe, def, parâmetro, return, valor padrão, argumento nomeado, docstring, escopo, e um exemplo que junta tudo num bolo.
9. [Marido de aluguel](09-tratamento-de-erro.md) — o que fazer quando o código quebra: procurar o erro no Google, o que é exceção, os erros mais comuns, try/except, except específico vs genérico, .get() como prevenção, finally, e um exemplo processando leituras de sensor com defeito.
