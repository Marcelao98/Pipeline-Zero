# 3. Python

Módulo de Python, focado só no que serve pra engenharia de dados. Começa pelo porquê de Python ser a linguagem da área e pelos fundamentos, e depois aplica a linguagem a dado. É um resumo do resumo, não um curso completo de Python.

1. [Python: o canivete suíço da engenharia de dados](01-por-que-python.md) — o que é Python, por que ele e não outra linguagem, onde ele aparece no ciclo de vida, e o que esse módulo vai (e não vai) cobrir.
2. [Preparando o terreno: o que você precisa instalar antes de escrever Python](02-preparando-o-terreno.md) — o que é interpretador e IDE, por que o curso usa VS Code, e o passo a passo pra instalar Python e VS Code no Windows.
3. [Variável e tipo de dado: como o programa guarda informação](03-variavel-e-tipo-de-dado.md) — o que é uma variável, como receber valor digitado com `input()`, os tipos básicos (string, int, float, bool), os operadores matemáticos, tipagem dinâmica, e um primeiro exemplo prático.
4. [Texto (string): o dado que mais dá trabalho pra limpar](04-texto-string.md) — por que texto livre é a sujeira mais comum em dado, indexação e fatiamento, métodos de limpeza (strip, upper/lower, replace, split, join), o `in`, f-string, e um exemplo de limpeza.
