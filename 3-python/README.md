# 3. Python

Módulo de Python, focado só no que serve pra engenharia de dados. Começa pelo porquê de Python ser a linguagem da área e pelos fundamentos, e depois aplica a linguagem a dado. É um resumo do resumo, não um curso completo de Python.

Python é a caixa de ferramentas do engenheiro de dados. Mas antes de sair tirando da caixa as ferramentas específicas de dado, a gente começa pela mais básica de todas, aquela que todo mundo conhece, todo mundo já usou (e quem não usou, um dia vai usar): a chave de fenda. O Bloco 1 é isso, o básico de Python.

1. [Python: a caixa de ferramentas do engenheiro de dados](01-por-que-python.md) — o que é Python, por que ele e não outra linguagem, por que caixa de ferramentas e não canivete suíço, onde ele aparece no ciclo de vida, e o que esse módulo vai (e não vai) cobrir.
2. [Bloco 1: a chave de fenda](1-chave-de-fenda/README.md) — o fundamento da linguagem: instalar o Python, variável, texto, condicional, loop, estrutura de dado, função e tratamento de erro.
