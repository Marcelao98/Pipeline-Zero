# Bloco 1: a chave de fenda

O básico de Python, a ferramenta mais simples da caixa. Cobre o fundamento da linguagem, do zero até o programa saber lidar com erro sem quebrar tudo.

1. [Preparando o terreno: o que você precisa instalar antes de escrever Python](01-preparando-o-terreno.md) — o que é interpretador e IDE, por que o curso usa VS Code, e o passo a passo pra instalar Python e VS Code no Windows.
2. [Variável e tipo de dado: como o programa guarda informação](02-variavel-e-tipo-de-dado.md) — o que é uma variável, como receber valor digitado com `input()`, os tipos básicos (string, int, float, bool), os operadores matemáticos, tipagem dinâmica, e um primeiro exemplo prático.
3. [Texto (string): o dado que mais dá trabalho pra limpar](03-texto-string.md) — por que texto livre é a sujeira mais comum em dado, indexação e fatiamento, métodos de limpeza (strip, upper/lower, replace, split, join), o `in`, f-string, e um exemplo de limpeza.
4. [Comparação e condicional: ensinando o programa a decidir](04-comparacao-e-condicional.md) — operadores de comparação e booleano, if/else, indentação, elif, operadores lógicos (and, or, not), condicional aninhado, e um exemplo que junta tudo.
5. [Repetição (loop): deixando o trabalho chato pro programa](05-repeticao-e-loop.md) — for com range(), for direto numa string ou lista, while, a diferença entre os dois, break e continue, e um exemplo processando leituras de sensor.
6. [Até dragões precisam de dados](06-estrutura-de-dado.md) — estrutura de dado contada numa história de RPG: dicionário, lista, tupla, set, enumerate(), list comprehension, e quando usar cada uma.
7. [Função: do pão com manteiga ao bolo](07-funcao.md) — o que é função e por que existe, def, parâmetro, return, valor padrão, argumento nomeado, docstring, escopo, e um exemplo que junta tudo num bolo.
8. [Marido de aluguel](08-tratamento-de-erro.md) — o que fazer quando o código quebra: procurar o erro no Google, o que é exceção, os erros mais comuns, try/except, except específico vs genérico, .get() como prevenção, finally, e um exemplo processando leituras de sensor com defeito.
9. [Fim do Bloco 1: antes de seguir pro Bloco 2](09-fim-do-bloco-1.md) — um respiro depois do básico: errar faz parte, por que isso foi só o básico do básico, por que nenhum tutorial substitui a prática, e onde achar exercício de graça.
